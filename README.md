Short jQuery("document").ready() Vanilla JS function.

How to use:
```
docReady(function(){
   //any code here
   console.log("docReady done!");
})
```
docReady-with-var works a liitle bit different: it checks is variable DOCREADY exist? If YES, it wait until DOCREADY will became TRUE or 1 - sometime it can be usefull for waiting for dynamic content or file.
